# EdgeKite

A simple EdgeKite Suite for IoT Connectivity.

EdgeKite is built to be simple and practical, focusing on doing one thing well.

**Why EdgeKite?**

- A simple EdgeKite Suite for IoT Connectivity

## Key Features

- A simple EdgeKite Suite for IoT Connectivity

## Technology Stack

- python
- python framework (Flask/Django/FastAPI or equivalent)
- Pytest for testing

## Installation

1. Clone the repository: `git clone https://github.com/irenascent/EdgeKite.git`
2. `cd EdgeKite`
3. Install in editable mode: `pip install -e .`

## Configuration

Most behavior is controlled via command-line flags:
- `--verbose`: enable detailed logging
- `--config <path>`: point to a custom config file
- `--dry-run`: preview changes without applying them
